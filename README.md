# AI Interview Prep

AI Interview Prep is an AI-powered web app that helps users get ready for job interviews. Users provide a job description and upload a PDF or DOCX resume, or describe their experience.

The app creates a personalized interview plan with a role-match score, technical and behavioral practice questions, potential skill gaps, and a day-by-day preparation roadmap. Users can revisit their recent plans and generate a tailored resume.

Built with React, Node.js, Express, MongoDB, and the Google Gemini API.
