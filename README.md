# 🤖 AI Interview Prep

AI Interview Prep is an AI-powered web app that helps users prepare for job interviews. 🚀 Users can provide a job description and upload a PDF or DOCX resume, or describe their experience.

✨ **Features**
- 🎯 Personalized interview plan with a role-match score
- 💻 Technical and behavioral practice questions
- 📊 Potential skill gaps analysis
- 📅 Day-by-day preparation roadmap
- 📝 Tailored resume generation
- 🔄 Revisit recent interview preparation plans

🛠️ **Tech Stack**

React, Node.js, Express.js, MongoDB, and Google Gemini API.
